# 無料話RSS置き場の作り

## パス規則

- `<サイト名>/<作品名>.rss`
- 例: `kuragebunch/senpai-kohai-ohabare.rss`
- 新しいサイトを足すときはサイト名のフォルダを増やすだけ
- 新しい作品を足すときはそのサイトのフォルダに作品ファイルを追加するだけ

## 現在のフィード

- サイト: くらげバンチ（フォルダ名: kuragebunch）
- 作品: 先輩と後輩、大暴れの日々（ファイル名: senpai-kohai-ohabare.rss）
- 内容: 無料になった話だけ。掲載だけの更新や有料のままの話は載せない。
- 基準ページ: https://kuragebunch.com/episode/12207421984387079388

## 更新のしかた

- 無料話が増えたら、その作品の .rss ファイルだけを差し替える
- URLは変わらないので、読者は登録し直さなくてよい
- チャット通知の監視（毎日午後1時ごろ）とは別に動かす。通知が残っている間は無料化を見逃さない。
